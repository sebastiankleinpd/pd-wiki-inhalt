# 🏭 Industriegebiet

Das Industriegebiet befindet sich nördlich von Frankfurt.

Im Industriegebiet werden Rohbestandteile weiterverarbeitet. Dabei entstehen Materialien, die für das Crafting benötigt werden.

Folgende Materialien können im Industriegebiet hergestellt werden:

- Aluminium  
- Karbon  
- Schwarzpulver  
- Seide  
- Stahl  

Diese Materialien dienen als Grundlage für weitere Herstellungsprozesse, wie beispielsweise die Fahrzeugteileverarbeitung, die Fahrzeugherstellung oder die Waffenherstellung.

Das Industriegebiet ist somit ein zentraler Ort innerhalb des Crafting-Systems.
